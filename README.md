# Sistemas de Big Data Aplicado

Repositorio de prácticas y análisis de datos desarrollados en Jupyter Notebooks, utilizando **Polars** para el procesamiento eficiente de datos y **Matplotlib** para la visualización.

## 📋 Descripción

Este proyecto recoge una serie de notebooks orientados al análisis de datos a gran escala, cubriendo desde la carga y transformación de datos hasta la generación de visualizaciones. El objetivo es aplicar técnicas de Big Data con herramientas modernas y eficientes en Python.
